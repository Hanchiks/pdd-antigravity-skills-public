# Pinduoduo skills для Antigravity

Набор содержит три навыка: `pinduoduo-buyer`, `pdd-operator` и `adb-wifi-qr`, а также отдельные правила в `rules/PDD-SECTION.md`. Инструкции по копированию находятся в файле `КУДА-КОПИРОВАТЬ.txt`.

Приватные данные, профили и сессии аккаунтов в этот репозиторий не входят. Локальный профиль можно создать на основе `skills/pinduoduo-buyer/assets/user-profile.example.json`; не добавляйте его в Git. Скриншоты и дампы также могут содержать личную информацию.

Навык оператора описывает внешние инструменты `pdd.py` и `chat.py`: их, равно как и авторизованных сессий, в наборе нет. Наличие навыков само по себе не подключает телефон и не подтверждает работоспособность этих инструментов.
