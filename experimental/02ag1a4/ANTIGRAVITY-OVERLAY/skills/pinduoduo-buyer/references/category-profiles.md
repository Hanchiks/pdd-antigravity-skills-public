# Профили категорий: что проверять до рекомендации

Это маршрутизатор, а не энциклопедия. Сначала определи категорию по назначению товара, затем применяй её поля. Профиль не заменяет [вопросы и категории](intake-and-categories.md) и [практику карточки](marketplace-playbook.md): он задаёт возможные обязательные поля и типовые доказательства.

## Как пользоваться

1. Определи категорию по тому, как товар используется, а не по слову в заголовке.
2. Выпиши поля профиля и проверь **применимость каждого** к конкретной вещи (см. ниже).
3. Для применимого обязательного поля, которое не подтверждено, ставь `conditional`, а не `eligible`.
4. Для безопасности, здоровья, детей, еды и дорогой техники порог выше: неподтверждённое критичное свойство не компенсируется ценой.
5. Пять этапов проверки карточки — каркас; содержание этапов 2–5 берётся из профиля, а не только из одежды.

## Применимость полей

Профиль — это набор возможных требований, а не анкета, которую надо заполнить любой ценой. Для каждого поля ответь:

1. Применимо ли оно к этому изделию? (У ручной отвёртки нет напряжения и патрона; у чехла нет ёмкости в Wh.)
2. Влияет ли оно на задачу пользователя?
3. Это обязательное условие или второстепенное свойство?
4. Чем оно подтверждается и достаточно ли этого подтверждения?

Неприменимое поле не блокирует товар и не даёт `rejected`. Неизвестное критичное поле даёт `conditional`. Подтверждённое нарушение обязательного условия даёт `rejected` — и этого достаточно для раннего отказа, не нужно проверять остальные этапы.

## Минимумы по категориям

| Категория | Обязательная идентификация | Что подтвердить о качестве | Красные флаги | Фокус отзывов |
|---|---|---|---|---|
| Одежда, обувь, текстиль | Точный SKU, цвет, размер; состав по частям; замеры изделия в см | Таблица размеров в см или замеры продавца; состав конкретной вещи; фото швов/горловины; отзывы о посадке, усадке и катышках по нужному SKU. Если данных нет — назвать неподтверждённое свойство | «100% хлопок» при пушистой синтетике; размер только по весу; смесь 95/5 под видом 100%; отзывы других SKU | Усадка, катышки, окрашивание, несовпадение размера/цвета, деформация |
| Электроника, техника, аккумуляторы | Для применимых устройств: полный номер модели с суффиксом, напряжение/мощность/частота, тип вилки, ёмкость в Wh. Для пассивных аксессуаров эти поля не применяются | Совместимость с точной моделью; заявленные режимы; сертификация для применимой категории и модели; гарантия/канал; отзывы о нагреве, реальной ёмкости, портах. Число зарядок — расчёт с ёмкостью устройства и КПД, а не номинал; счётчик отзывов — не доказательство | «Универсальная» совместимость; mAh без напряжения; подмена модели; активация до проверки; серые «восстановленные» | Нагрев, реальная ёмкость, шум, зарядка, отвалы, ремонт, прошивка/регион |
| Косметика, гигиена | Бренд, точное название, объём, партия, срок годности; состав (INCI) | Регистрация/уведомление для применимой категории по действующему реестру; целостность упаковки; официальный канал или подтверждённая авторизация; отзывы о реакции. Без партии/срока — `conditional` | Нет партии/срока; «лечебные» обещания; цена сильно ниже рынка; переклеенные этикетки; регистрация «на всё» | Раздражение, запах, текстура, подделка, аллергия, несоответствие составу |
| Посуда, кухня, контакт с едой | Материал каждой контактной части; объём/размеры; покрытие; допустимая температура | Применимый стандарт пищевого контакта для готового изделия; состав комплекта; отсутствие повреждений; отзывы о покрытии/запахе. Марка стали — не доказательство безопасности | 304/316 как «гарантия безопасности»; «食品级» без документа; тонкое покрытие; запах | Ржавчина, сколы, запах, деформация, покрытие, размер меньше заявленного |
| Детское, игрушки | Возрастная группа и пригодность для возраста ребёнка; мелкие съёмные детали; отделяемые магниты; шнуры; батарейки и доступ к батарейному отсеку; острые кромки | Безопасная конструкция под заявленный возраст; для точной категории — применим ли сертификат или стандарт (например CCC для игрушек из перечня) и какое первоисточное доказательство это подтверждает. Если применимость или доказательство не проверены — пометить «неизвестно», а критичные свойства оставить `условно подходит`; слова продавца «сертифицировано» доказательством не являются; CCC не требовать у каждой игрушки | Игрушка «0+» с мелкими деталями; магниты; шнуры; хрупкий пластик; нет предупреждений | Поломки, острые края, запах, размер, реальный возраст, батарейный отсек |
| Авто и мото | Марка, модель, год, поколение; номер детали; сторона | Для тормозов/руля/шин/ремней — проверяемый канал и точная совместимость; для аксессуаров — размеры/крепления; отзывы по нужной модели | «Оригинал» без номера; изменённые даты шин; safety-детали без канала; универсальные крепления | Люфт, шум, несовпадение, крепления, ресурс, безопасность |
| Мебель, крупногабарит | Габариты, материал, нагрузка, комплектация | Схема сборки; крепёж; реалистичная нагрузка; отзывы о сборке и устойчивости. Вес/объём упаковки — отдельный риск доставки, а не свойство качества | «Массив» = шпон; размеры без единиц; скрытая комплектация; хрупкость | Сборка, шатание, сколы, запах, несовпадение размеров |
| Инструменты, DIY | Для применимых: напряжение/мощность, патрон/оснастка, класс защиты. У ручного инструмента эти поля не применяются | Применимая сертификация; защита; совместимость оснастки; отзывы о люфте/перегреве. Тип привода определяет, какие поля вообще нужны | 220 В без запаса; «профессиональный» без данных; дешёвые батареи без BMS | Перегрев, люфт, реальная мощность, ресурс, шум |
| Продукты, БАДы | Наименование, состав, срок, партия, производитель | Для продуктов — применимая лицензия/маркировка; для БАДов — регистрация; канал с прослеживаемостью; для импорта — допустимость | Нет срока/партии; «лечит»; ввоз запрещён; неизвестный производитель | Вкус, запах, упаковка, срок, состав, реакция |
| Зоотовары | Вид/размер животного, материал, размеры | Безопасные материалы, отсутствие мелких съёмных деталей; отзывы по размеру и погрызам | Мелкие съёмные части; токсичный пластик; «для всех» без размеров | Погрызы, запах, размер, аллергия, безопасность |
| Прочее | Назначение, размеры/совместимость, материал | 2+ сопоставимых предложения; ключевое свойство под задачу; отзывы; явные неизвестные | Нет данных о материале/размере; продавец уходит от ответа | По назначению товара |

## Универсальный порог качества

- **Минимум два сопоставимых предложения.** Одна карточка — это не выбор, а первый найденный товар. Если рынок узкий, покажи, что искал, и почему альтернатив нет.
- **Заявление продавца — не доказательство.** «100% хлопок», «оригинал», «сертифицировано», «премиум» без проверяемого источника оставляют товар в статусе `conditional`.
- **Доказательство должно относиться к нужному свойству.** Отзывы по нужному SKU подтверждают наблюдавшийся опыт, но не долю дефектов; сертификат подтверждает категорию/модель, но не партию; авторизация продавца подтверждает канал, но не качество работы.
- **Допуск — по всем применимым условиям, от которых зависит пригодность**, а не по одному удобному признаку. Один источник может покрывать несколько условий; повторение одного заявления новых оснований не добавляет. Неприменимое поле не входит ни в допуск, ни в неизвестности.
- **Количество отзывов — ориентир глубины, не фильтр.** Если данных мало, назови свойство, которое не удалось оценить, а не число недостающих отзывов.
- **Дешёвый небрендовый товар может быть лучшим выбором**, если профиль категории выполнен и риск понятен. Бренд сам по себе не повышает статус.
- **Цена ниже рынка — вопрос, а не приговор.** Проверь, за счёт чего: комплектация, модель, партия, канал, состояние. Неизвестную причину так и назови.
- **Не выдавай первый найденный товар за финал.** В ответе должно быть видно, почему отклонены альтернативы и что ещё осталось проверить.
