# Правила работы оператора Pinduoduo (синтетическая фикстура для тестов)

Это **обезличенная синтетическая фикстура**. Она не является копией действующего правила Antigravity и не содержит пользовательских данных. Используется только для проверки миграции в офлайн-тестах.

1. Сначала проверить карточку и обязательные поля категории.
2. Не нажимать `立即支付`, `提交订单`, `确认支付`, `去结算`, `直接拼成`, `全选`.
3. Сравнивать цену по умолчанию до китайского склада; международная часть не равна нулю.
4. Не публиковать адрес, телефон и платёжные данные.
