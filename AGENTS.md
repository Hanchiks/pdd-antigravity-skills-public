# Индекс репозитория для агента

Этот файл — короткая карта проекта и границы безопасности. Он не заменяет
`runtime/README.md`, `BASELINE.md` и инструкции навыков, а помогает не
перепутать рабочую версию, экспериментальный кандидат и архив аудита.

## Что где лежит

- `runtime/pdd.py` — **рабочая** версия оператора Android через ADB.
- `runtime/chat.py` — рабочие веб-чаты через отдельный профиль Chrome.
- `runtime/common.py` — конфигурация, состояние, журналы и межпроцессные
  блокировки.
- `runtime/tests/` — офлайн-тесты рабочей версии и общих модулей.
- `runtime/experimental/pdd-02d1f/pdd.py` — **экспериментальный кандидат**,
  не принят в рабочую версию.
- `runtime/experimental/pdd-02d1f/tests/` — отдельные тесты кандидата.
- `runtime/config.example.yaml` — отслеживаемый шаблон конфигурации без
  секретов. Рабочий `runtime/config.yaml` создаётся локально и в Git не входит.
- `runtime/requirements*.txt` — зависимости; `requirements-test.txt` нужен
  только для офлайн-тестов и не тянет браузеры.
- `skills/pinduoduo-buyer/` — навык покупателя, калькулятор и справочники.
- `skills/pdd-operator/` — навык оператора.
- `skills/adb-wifi-qr/` — вспомогательный навык подключения ADB по Wi-Fi.
- `rules/PDD-SECTION.md` — правила Pinduoduo.
- `experimental/02ag1a4/` — очищенный исторический снимок DeepSeek Harness
  со статусом `not_deployable`; это не версия `pdd.py` или `chat.py`.
- `docs/bridge-proposal.md` — только текстовое предложение моста к устройству,
  без реализации.

## Версии оператора

| Роль | Файл | Статус |
|---|---|---|
| Рабочая | `runtime/pdd.py` | установленная версия, на неё рассчитаны `runtime/tests` |
| Кандидат | `runtime/experimental/pdd-02d1f/pdd.py` | не принят; отдельного обоснования для продвижения нет |
| Архив аудита | `experimental/02ag1a4/` | `not_deployable`: инструменты проверки, не оператор |

Кандидат не заменяет рабочую версию автоматически и не должен попадать в
`runtime/pdd.py` без отдельного решения, тестов и документированного
обоснования. Такого обоснования сейчас нет. Проверяйте версии раздельно:

```bash
python3 scripts/verify_versions.py
```

Скрипт печатает, какой файл и в каком каталоге проверяется, и завершается
ненулевым кодом, если падает хотя бы одна версия.

Не устанавливайте `experimental/02ag1a4/`, не запускайте его миграции, не
подделывайте его манифест и не используйте фиктивные значения как
подтверждение оригинального результата. Его файлы, статус и README не
меняются.

## Безопасность

- Нет реального телефона, ADB к реальному устройству, браузера с
  пользовательским профилем, реальных аккаунтов, чатов, адресов, телефонов,
  паролей, токенов, cookies и сессий.
- Все примеры, фикстуры и тесты используют только синтетические данные.
- Жесты `scroll`/`swipe` и длительное нажатие (`tap --long`, `tapel --long`,
  `tap_real(long_ms≠0)`) заблокированы. Офлайн-тесты этот запрет не снимают.
- Не отключайте защитные проверки ради тестов и не обходите блокировки
  через env/CLI/config.
- Не запускайте `pdd.py`/`chat.py` так, чтобы они могли обратиться к
  устройству, браузеру или сети, без отдельного поручения. Разрешены чтение
  кода, статический анализ, `--help`, офлайн-тесты и скрипты на синтетике.
- Не создавайте и не запускайте мост к компьютеру или телефону. Для п.4.9
  существует только текстовое предложение `docs/bridge-proposal.md`.
- Наличие репозитория и навыков **само по себе не подключает** телефон,
  браузерный профиль или локальные сессии. Доступ нужно проверять отдельно.

## Канонические офлайн-проверки

Из корня репозитория:

```bash
python3 -m unittest discover -s runtime/tests -t runtime
python3 scripts/verify_versions.py
```

Из `runtime/experimental/pdd-02d1f`:

```bash
PYTHONPATH=.:../.. python3 -m unittest discover -s tests -t .
```

Из `skills/pinduoduo-buyer/scripts`:

```bash
python3 -m unittest discover -s . -p "test_*.py"
```

Из `skills/adb-wifi-qr/scripts`:

```bash
python3 -m unittest discover -s . -p "test_*.py"
```

Тесты создают синтетическую среду через `runtime/test_env.py` и
`runtime/config.example.yaml`; пользовательский `runtime/config.yaml` не
требуется. Папки `experimental/02ag1a4/` эти команды не проверяют.

## Ограничения сред

Проверено здесь: Linux, Python 3.12.3, Pillow 10.2.0, PyYAML 6.0.1, `flock`,
синтетические ADB/UI/скриншоты/CDP-заглушки.

Не проверялось здесь: Windows и ветка `msvcrt`, пути Windows, запуск Chrome,
реальный ADB по Wi-Fi, реальный `uiautomator`, реальные жесты, реальные
веб-чаты и вложения, фактические ACL/`umask`. Подробности и таблица
параметров — в `runtime/README.md`. Не обещайте работу на ОС или платформе,
которая не была проверена.
