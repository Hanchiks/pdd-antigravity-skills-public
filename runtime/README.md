# Рабочие инструменты Pinduoduo

Здесь сохранены установленные рабочие версии оператора: `pdd.py` управляет Android через ADB, `chat.py` работает с веб-чатами через отдельный профиль Chrome. Вспомогательные модули, шаблон сообщения, диагностические JAR и их исходники входят в комплект.

## Подготовка в Windows

1. Установите Python, Android SDK Platform Tools (ADB) и Google Chrome.
2. В каталоге `runtime` установите зависимости: `python -m pip install -r requirements.txt`.
3. Скопируйте `config.example.yaml` в `config.yaml` и при необходимости задайте расположение ADB и Chrome. Конфигурация локальная и исключена из Git.
4. Подключайте Android только с разрешения владельца. Для входа в веб-чаты служит `python chat.py login`; данные входа остаются в локальной папке `profile/`.

`python pdd.py --help` и `python chat.py --help` показывают команды. Для ввода текста может потребоваться команда `install-adbkeyboard`: она отдельно скачивает сторонний APK и проверяет его по встроенному SHA-256 перед установкой. APK в репозитории нет.

**Ограничение жестов:** до независимой приёмки геометрии и защиты жестов не используйте реальные `scroll`/`swipe`; это ограничение задано правилами и не гарантируется кодом. Состояние телефона, сессии браузера, скриншоты и рабочие журналы в репозиторий не входят. Синтетические тесты не подтверждают работу на конкретном телефоне или в текущих версиях веб-чатов.

Для локальной проверки без телефона: `python -m unittest discover -s tests`.
