# Pinduoduo Buyer — инструкция по запуску

Версия 1.0.1. Маршрут и личные данные задаются пользователем в локальном приватном профиле. Собрано 27 октября 2026 года из трёх предоставленных отчётов: DeepSeek, Qwen, Doubao — в указанном пользователем порядке. Пакет предназначен для русскоязычного выбора товаров на китайском Pinduoduo, не на Temu.

## Что изменилось в 1.0.1

Маршрут доставки должен быть подтверждён пользователем или указан в разрешённом локальном профиле. Агент не уточняет повторно уже известные сведения. Сравнение идёт по цене до китайского склада; перевозка после склада не включена, а не бесплатна. Неизвестный тариф не останавливает поиск. Предупреждение остаётся только для конкретного необычного риска товара; полный расчёт до получателя — по отдельному запросу.

**Приватность:** приватный профиль, скриншоты с реквизитами, сессии и данные аккаунтов не входят в этот пакет. Храните такие данные только локально и не загружайте в репозиторий.

Для обновления замените прежнюю папку `pinduoduo-buyer` целиком новой либо замените установленный архив средствами своей среды. Для режима без установки используйте обновлённый `assets/PORTABLE_PROMPT_RU.md`. Не держите одновременно две версии одинакового скилла.

## Что подготовлено

Пакет содержит одну папку `pinduoduo-buyer` с главным `SKILL.md`, метаданными, справочниками, формами и небольшим автономным калькулятором. Если пакет получен архивом, внутри лежит та же папка. Сырые исходные отчёты в публичную поставку не входят; сохранён только аудит источников. Скилл не установлен автоматически ни в Antigravity, ни в ChatGPT и не подключён к телефону.

По умолчанию агент уточняет только важное, ищет достаточно качественное максимально дёшево и предлагает столько реальных вариантов, сколько оправдано запросом и результатами. Он должен показать самый дешёвый допустимый вариант и выгодный компромисс с минусами; не должен тратить весь бюджет, предпочитать бренд без оснований или заполнять список неподходящими позициями.

Цена считается по конкретному размеру/модели/комплекту, а не по обложке. Неизвестная доставка остаётся неизвестной. «Цена не важна» переключает приоритет на характеристики; просто большой бюджет этого не делает.

## Antigravity

Распаковать архив (если пакет пришёл папкой — использовать её). Поместить целиком папку `pinduoduo-buyer` внутрь `.agents/skills/` рабочего проекта. Проверить, что итоговый путь имеет вид:

```text
<папка вашего проекта>/.agents/skills/pinduoduo-buyer/SKILL.md
```

Не создавать лишний вложенный уровень `pinduoduo-buyer/pinduoduo-buyer`. Не копировать только SKILL.md без справочников. Открыть этот проект, обновить список настроек/начать новый разговор и проверить, что агент видит скилл. В Antigravity IDE список можно проверить в Customizations. При несовпадении интерфейса свериться с документацией вашей версии [I1].

Стартовая фраза:

> Примени pinduoduo-buyer. Сначала проверь реальные инструменты доступа к телефону или Pinduoduo. Затем помоги выбрать [товар]. По умолчанию ищи качественное как можно дешевле, уточни важные параметры и покажи несколько подходящих вариантов. Ничего не покупай и не отправляй продавцам без моего разрешения.

## ChatGPT Desktop

В интерфейсе ChatGPT, где для вашего рабочего пространства доступно управление Skills, открыть **Plugins → Skills → Create → Upload from your computer** и выбрать архив пакета (`skill.zip`). Если архива нет, соберите его из папки `pinduoduo-buyer` или используйте режим без установки ниже. Дождаться завершения проверки файла и проверить, что скилл доступен/установлен. Возможность импорта и использования зависит от продукта, рабочего пространства и разрешений [I2]. Не считать обычное прикрепление архива к сообщению установкой.

Если нужных пунктов нет в Desktop, проверить тот же аккаунт/пространство в веб-интерфейсе и фактическую доступность функции. Не предполагать автоматическую синхронизацию между всеми поверхностями.

Резервный способ без установки: прикрепить файл `assets/PORTABLE_PROMPT_RU.md` в новый разговор и написать:

> Прочитай этот файл целиком и используй как инструкции для подбора товаров в этом разговоре. Начни с проверки доступных инструментов. Мой запрос: [товар].

Это инструкции конкретного разговора, не гарантированно автоматически вызываемый скилл. Компактный файл содержит основную процедуру; полный архив дополнительно содержит подробные справочники и аудит. Сырые исходные отчёты в публичную поставку не входят. Название ChatGPT Desktop не означает, что установленный скилл автоматически умеет управлять телефоном.

## Что требуется для работы именно в приложении на телефоне

Нужны три отдельные части: модель, этот скилл и разрешённый инструмент, который реально читает экран телефона и выполняет нажатия/ввод/прокрутку. Возможность зависит от ОС телефона, конкретного адаптера и среды модели. Сам навык не устанавливает драйвер. В репозитории инструменты оператора находятся отдельно в `runtime/`; их нужно настроить по `runtime/README.md`.

Спецификация нужных действий и разрешений находится в `references/device-and-permissions.md`. Она намеренно не привязана к выдуманному имени MCP-сервера. При выборе адаптера нужно проверить поддержку ОС, чтение текущего экрана, управление, безопасность, ограничения и реальные функции — не только маркетинговое описание.

При уже подключённом адаптере агент сначала делает безопасное чтение экрана. Без него переходит к браузеру или скриншотам и явно сообщает ограничения. Для анализа скриншотов полезны: карточка с магазином; экран выбранного SKU; параметры; содержательные отзывы; условия доставки. Не отправлять пароли, SMS-коды, банковские реквизиты или полный адрес.

## Первое использование

Пример: «Найди летнюю футболку, хорошую и недорогую». Агент должен спросить только то, что влияет на выбор: лёгкая или плотная, нужная посадка/размеры, цвет и потолок цены. Если всё уже указано, вопросов меньше или не будет.

Пример: «Найди органайзер 30×20×10 см, до 40 юаней, бренд неважен». Агент не должен предлагать более дорогую марку ради марки. Он должен сравнить точные размеры и комплекты и не принять цену мини-версии за цену нужного размера.

Пример: «Цена не важна, нужны лучшие свойства под мою задачу». Агент переключает приоритет, но всё равно объясняет, за что доплата.

Поиск не включает заказ, оплату, изменение аккаунта, вступление в оплачиваемую группу, оформление рассрочки, подтверждение получения или отправку сообщений. Разрешение на вопросы продавцам можно дать отдельно на текущий поиск.

## Что находится в архиве

- `SKILL.md` — основной порядок работы и ограничения.
- `references/decision-policy.md` — цена, достаточное качество, компромиссы и полная стоимость.
- `references/intake-and-categories.md` — вопросы и критерии для одежды, обуви, дома, техники, косметики, детских и автомобильных товаров.
- `references/category-profiles.md` — обязательные поля и минимум качества по категориям, чтобы подбор не сводился к одежде.
- `references/marketplace-playbook.md` и `chinese-glossary.md` — карточки, продавцы, отзывы, метки, китайские термины, 32 шаблона поиска и сообщения продавцам.
- `references/device-and-permissions.md` и `output-contract.md` — управление, разрешения, доказательства и формат выдачи.
- `references/evidence-audit.md` — что перенесено, что ограничено, что проверено извне и статус исходных отчётов (сами отчёты в публичную поставку не входят).
- `assets/` — шаблоны профиля/поиска, компактный промпт и синтетический пример расчёта `assets/synthetic-price-example.json` с явной пометкой `"synthetic": true`.
- `scripts/` — автономный расчёт стоимости и его unit-тесты.
- `references/acceptance-tests.md` — 52 сценария: 33 базовых, 5 для не-одежды, 6 проверок согласованности решений и 8 регрессий 02B–02C.
- `references/shipping-profile.md` — правила доставки; `assets/user-profile.example.json` — пустой шаблон профиля.

Приватный профиль не входит в комплект. Пустой `user-profile.example.json` — общий пример; при необходимости создайте локальный профиль самостоятельно. Порог заметной скидки 25% — настраиваемый ориентир, не научная граница выгодности.

## Проверка и ограничения

Калькулятор работает локально на стандартной библиотеке Python 3.10+, не подключается к сети, не получает токены и не выполняет покупки. Он проверен 36 unit-тестами на синтетических данных; ещё 58 тестов покрывают валидатор доказательств (всего 94). Запуск из папки скилла:

```bash
python scripts/compare_prices.py --help
python scripts/compare_prices.py assets/synthetic-price-example.json --basis china
python -m unittest discover -s scripts -p 'test_*.py' -v
```

Арифметическая проверка не подтверждает правдивость введённой цены или качество товара. Весь профиль поведения ещё нужно проверить в выбранной модели на вашем устройстве. В процессе подготовки не выполнялись реальные поиски в вашем аккаунте, не проверялись мобильные кнопки и не тестировалась работа с реальным телефонным мостом.

Внешняя проверка исходных утверждений была выборочной: правила/стандарты и текущие сведения об установке. Полного подтверждения всех трёх отчётов нет. В частности, убраны автоматические отказы дешёвым/небрендовым товарам и необоснованные универсальные требования CCC. Аудит указывает происхождение каждого существенного изменения.
